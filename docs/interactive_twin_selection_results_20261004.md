# Physics model selection：7320 / 45621 实测结果

基于 `170bc15`，方法与新测试在运行前提交为 **`5db8097`**。模式是 **SIM_TO_SIM_BLIND_SYSID，条件动力学 A**。所有实验已完成；没有修改或替换 f5dcc6f / cd61660 / 3e5e856 的成功基线。

## 结论

- **7320 回归通过。** 新二参数选择在旧 P4 上，原阻力 RMSE 与旧成功值完全相同；非零阻力更好。新留出上，相对仅结构更新分别降低 **80.8% / 84.9%**。
- **45621 的最小静摩擦扩展确实改善了未见动作预测。** 相对仅结构更新，位置 RMSE 从 **0.01382 降到 0.01120 mm（19.0%）**；相对二参数模型降低 **31.9%**。启动延迟和 dwell 误差也下降。
- **预测改善与参数认证分开。** 三参数验证残差仍超过预注册充分性门槛 10，故按本轮冻结规则输出 `MODEL_MISMATCH`，不接受单点阻力值、不将扩展升级为成功基线。这是一次 DEV 外单配置的预测改善证据，尚未通过跨资产物理辨识的完整验收。
- `tau_s` 的收益不普遍：它改善 7320 原阻力和 45621 的新动作，但在 7320 非零阻力下比二参数模型明显变差。

## 本轮修复与冻结内容

1. 收齐全部可用 low/high forward、dwell 和 reverse 后统一评分，保留所有候选损失、相对权重和 top-5。早期动作不再不可逆地剪枝。
2. 物理证据只使用 EE translation / rotation / velocity、启动和停止响应。q/qdot 只做一致性与安全诊断。姿态与速度使用联合协方差 whitening；同一时间序列不当作 240 Hz 独立试验累加置信度。
3. 噪声来自已有 DEV robot-only、真实接触重复和 zero-drive 日志。13 对命令相同的重复轨迹逐值一致；用短时波动包络提供有限尺度。位置尺度约 **0.130–0.225 μm**，旋转 **0.866–2.534 μrad**，启动时间 **6.806 ms**。它们是确定性模拟器的重复性/波动尺度，**不是硬件传感器精度，也不包含共同系统偏差**。
4. 保留两版所有已有训练产生的结构候选并去重，未调用或修改结构 fitter：7320 为 9 个结构×9 点＝81；45621 为 5×9＝45。不是只挑旧 held-out 的成功模型。
5. 仅在所有二参数候选验证不充分时增加静摩擦：每资产最多 12 个点，使用统一 `tau_s=tau_c+{0.004,0.012}`。锚点只按 train 数据选取，两个 7320 阻力条件合计也只有 12 个点。没有继续细化网格。
6. 新参数只写入 PhysX 原生 `staticFrictionEffort`；运动摩擦和阻尼仍为原 `tau_c,b`。没有脚本给门施力或执行期修改门关节状态。配对检查表明同命令下只改 τs 会改变实际响应，例如 EE RMS 差异 0.00528 mm；并非只保存了配置字段。
7. 抓取、contact、proxy、base/mobile recovery、关节余量、机器人响应及控制器代码均未改动。6 项针对性测试通过；实验后源文件哈希与运行前冻结值一致。

当前 τs 扩展在 7320 原阻力和 45621 上通过了“相对验证改善＋新测试改善”，但未通过预注册的**绝对充分性**门槛。因此仍保留二参数 family 并记录 mismatch；没有在看到好看的测试数字后放宽门槛。

## 集合与可观测性

三种 reference 条件都安全获得了四个动作。反向实测 excursion 分别为 **7320 原阻力 1.247 mm、非零阻力 1.103 mm、45621 1.068 mm**，均超过原 1 mm 门槛。未改命令、未降低门槛。此前 45621 的不足运动是候选预测下的跳过决定；本轮在预测安全时实际执行同一反向命令后得到可用观测。

没有候选通过绝对充分性门槛，因此没有强制输出狭窄“摩擦置信区间”。保留的**测试范围**为：

|资产|二参数测试集合|静摩擦扩展测试范围|

|7320 两条件|81 个结构×参数组合；τc∈{0,.004,.012}，b∈{0,.3,1}|12 个组合；τc∈[0,.004]，b∈[0,1]，τs∈[.004,.016]|
|45621|45 个结构×参数组合；同一九点网格|12 个组合；τc=.012，b∈[0,1]，τs∈[.016,.024]|

## 剩余首个瓶颈

剩余阻塞是**当前结构×最小动力学候选对完整响应的模型充分性不足**。45621 的 D 已将验证位置 RMS 降到 0.01829 mm、增量 dwell RMS 降到 0.03190 mm，但仍有约 0.209 mrad 姿态误差，且 stop-response 项约占总验证 loss 的 70.5%。其新测试启动误差仍有 0.15417 s。相对确定性模拟器的很小波动尺度，这些是系统残差。

本轮证据不能独立归因于轴偏差、机器人响应偏差或接触平衡偏差中的某一项；也不能据此断言 τs 网格更细即可解决。最小静摩擦扩展有预测价值，但不足以把剩余偏差全部解释成真实铰链摩擦。按冻结预算停止，没有再加参数或回到接触/几何调试。

## 实际运行、安全和边界

- 新增 **260 次 native 物理试验，260 次正常完成**；另复用 370 次已有响应用于当前候选库与 reference。旧训练数据复核单独保存。
- 新试验全部建立 bilateral hold；最小 joint margin **0.169227 rad**，峰值日志夹持接触载荷 **0.59547 N**。没有 native 安全失败。
- 每次条件试验仅开始时初始化一次，真实接触重新建立，再由仿真自主演化。没有 attachment/weld、直接物体驱动、逐帧实测 q 或门角 replay。
- 现有安全监督含 simulator-only contact 信息；切向 slip 并非完整可观测。本轮未重新认证完整接近→抓取→5°任务，也未运行真机。
- 只覆盖 7320 两种阻力和 45621 一个既有可执行配置；不称为四资产或所有 household objects 泛化。原 12 场景失败记录保留。
