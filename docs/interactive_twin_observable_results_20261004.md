# Observability-aware probe：7320 / 45621 实测结果（2026-10-04）

基于 `3e5e856`，实验方法在实际 reference probe 前冻结并提交为 `6e4179d`。原成功 baseline 不变。模式为 **SIM_TO_SIM_BLIND_SYSID，条件动力学辨识 A**。

## 结论

本轮完成了有界协议的实现与两资产实测；**未通过“7320 不明显退化”的整体验收，不替换 `3e5e856` 成功版本**。反向低于 1 mm 不再阻塞整个流程，但流程完成、预测改善和物理参数可辨识是不同结论。

## Probe、运动量与候选集合

每个动作是独立的条件试验：从同一份可观测稳定抓持快照初始化一次，重新建立真实物理接触，然后自主演化。不是连续不重置的整段主动操作。没有 attachment、接触缓存复制、物体外力或逐帧设置实测 q / 门角。

|资产 / 条件|动作顺序|实测 excursion mm（对应顺序）|EE 累计路径 mm|结构×物理训练支持集|状态|
|---|---|---|---:|---|---|
|7320 / 非零阻力|low_forward → high_forward → stop_dwell|0.974 / 2.052 / 0.247|3.672|45 → 2 → 1 → 1|`GRID_PREFERRED_NOT_CONTINUOUSLY_IDENTIFIED`|
|7320 / 原阻力|low_forward → high_forward → stop_dwell → reverse|1.018 / 2.096 / 0.283 / 1.247|6.874|45 → 1 → 1 → 1 → 1|`GRID_PREFERRED_NOT_CONTINUOUSLY_IDENTIFIED`|
|45621 / 原阻力|low_forward → high_forward → stop_dwell|0.952 / 2.023 / 0.230|3.678|45 → 1 → 1 → 1|`UNIDENTIFIABLE_MODEL_RESPONSE_RESIDUAL`|

反向 excursion 只统计切换后的反向窗口，累计路径包含该动作的前向前缀。其他 excursion 是相对动作初帧的最大位移。累计路径包含测量抖动，不等于净开门行程。

1 mm fitter 门槛保持不变；不足的 reverse 不做结构拟合，也不伪造为可用数据。低于 1 mm 的低速动力响应仍可比较，因为结构候选已由既有长轨迹建立。

结构分布来自长 EE SE(3) 动作的四段拟合、leave-segment-out、四次有序 block bootstrap，以及联合拟合的局部 Hessian/covariance；可用的独立反向段才参与。最多五个结构、九个物理网格点。每个点最多四个短预测动作，共每资产 180 次 native 预测，未追加优化点。

参数网格：`tau_c={0,0.004,0.012}`，`b={0,0.3,1}`。下表为测试网格上的支持集合，**不是连续物理参数的统计置信区间**。

|---|---|---|---:|---|
|7320 / 非零阻力|[0.012, 0.012]|[1.0, 1.0]|1|True|

单点 `GRID_PREFERRED_NOT_CONTINUOUSLY_IDENTIFIED` 仅表示当前离散网格选出一个预测器。多个组合仍受支持或验证残差不足时输出 `UNIDENTIFIABLE` 和可行集合，不把 current/effort 当作已标定的 hinge torque。

45621 的 45 个组合**均未通过**验证残差门槛；保留整个测试范围表示拒绝给出虚假的窄区间，不表示这 45 个模型都通过验收，也不能把该范围理解为完整连续参数的置信区间。

主动选择记录保存在 `decision_*.json`，均先于相应 reference 执行；响应之后保存 `posterior_*.json`。后续动作按剩余候选的噪声归一化预测分歧/时长排序。7320 的支持集很早缩到单点，后续分歧为零并按固定顺序打破平局；**没有证据证明此时主动策略比固定动作顺序更优**。

## 首个瓶颈与后续边界

7320 的首个失败层是模型选择与未见动作预测，而不是抓取、接触安全或反向门槛。保存的事后诊断显示：在本轮 S4 下，`(tau_c,b)=(0,0)` 的 low-forward EE RMSE 为 0.00755 mm，但冻结多信号评分更偏好 `(0.004,0)`（EE RMSE 0.02998 mm），后者的 q / rotation 误差较低。这是具体的指标取舍证据；新旧结构候选分布也发生变化，尚不能把全部回归退化归因于单一权重。

45621 的首个失败层是**结构/物理候选无法充分解释响应**：45 个候选中最好的验证归一化 RMS 为 **19.80**，仍超过冻结门槛 10；被选预测器为 22.96。启动延迟是较大的残差项，dwell 的位移、q 和姿态残差也没有消失。不是安全停机造成数据中断；反向预测仅 0.888 mm，按原门槛跳过。现有试验不能独立区分结构偏置、冻结机器人响应误差和等效阻力混淆的贡献，因此报告模型响应不足与物理不可辨识，不武断归因为单一轴误差或宣称增加摩擦即可解决。

不以 GT 轴误差选模型。事后轴误差更小的模型也不保证行为预测更好。若继续，应在 DEV 上先检查模型不确定性覆盖和多信号噪声/偏置是否校准充分，再冻结新测试动作；本轮不根据已看过的测试调参。
