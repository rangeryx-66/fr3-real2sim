# V7 cross-object protocol

Reference `25e2189`; xArm7 + native G1, simulated wrist RGB-D/SAM3,
known articulation axis/state and registered station, approximate actuators,
ideal virtual wrist six-axis load cell. Native collision geometry is used for
safety, never to supply visual grasp/contact scores. The four doors are prior
development objects; this is cross-object capability evaluation, not an unseen
population success estimate.

The prephysical object set is fixed: revolute 45936, 46427, 45600, 45606;
prismatic 19179, 45290, 27044, 45746. Two independently seeded configurations
per asset, one constant and one smooth localized passive-friction family,
secretly shuffled. Positive-density mass/COM/inertia are generated consistently.
The public machine manifest commits source hashes, case order and hidden-file
SHA256 before research execution. The Agent does not read seeds, mass properties,
native resistance readbacks, authored efforts or hidden profiles online.

The user authorizes a conditional schedule: complete the current drawer
engineering tests first. If sustained bidirectional native contact is not
established, execute the four preselected doors (eight configurations) and keep
the drawer configurations deferred. This is a recorded scope change before
research outcomes, not removal or replacement of failing benchmark objects.
Deferred cases remain NOT_EXECUTED / PRISMATIC_ENGINEERING_UNRESOLVED.

Each fresh episode uses the same instructions: inspect actual wrist RGB, SAM3,
depth and measured geometry; choose useful reachable views; automatically rank
existing grasp families; check complete current-state native execution; approve
bounded contact operations; inspect feedback and recover in the same scene when
safe alternatives remain. No saved grasp/view, GT pose correction, clamp increase,
physics change or relaxed safety threshold is allowed. Maximum four physical
handle acquisitions, four Agent-selected view adjustments and forty operations.
Each operation stops or reaches a verified unloaded boundary before slow Agent
reasoning. HARD stops remain authoritative. Owned actors execute sequentially.
Research episodes have finite maxima of 5400 s wall and 2400 s simulation,
including reserved 300 s wall / 90 s simulation for guarded exit. These accommodate
fresh perception and bounded alternative-path searches; they are resource caps,
not minimum durations or increased contact-loading timeouts. Stop after complete
useful validation or when no safe informative action remains.

Prioritize acceleration-rich opening FIT, overlapping different-speed reverse
FIT, then a complete distinct-profile VALIDATION. Targets and profiles are
declared before execution from fresh planning and measured state. Meaningful
door range is 20–30 degrees when feasible; drawer goal is 80–150 mm when its
engineering prerequisite passes. Targets are not success claims or fixed poses.
Optional range expansion follows primary validation; no new FIT is admitted
after inspecting primary validation results. An optional additional trajectory
is labeled held-out expansion, with extrapolation beyond FIT support explicit.

Interrupted FIT is eligible only under its predeclared intervals and existing
physical-transmission/quality rules. Failed target status is preserved. Incomplete
VALIDATION is never independent validation. Apply segment-local common SG121
filtering to torque and all bases, compensate tool inertia once, fit/select only
FIT, compare constant and smooth nonnegative resistance on identical held-out
data, and independently integrate held-out measured effort from one initial state.
Unsupported inertia/mass or damping remains unknown with excitation/conditioning
and uncertainty, rather than being inferred from a low training residual.

Report every configuration: acquisition, actual range/reverse travel, recovery,
FIT/VALIDATION completeness, parameter estimates/errors, held-out effort and free
motion RMSE, safety/parking, wall time and bytes. Keep denominators separate by
stage, joint type and executed/deferred status. Reveal completed-subset truth
only after its final online decisions; deferred truth stays hidden. Authored
inertia is not an independent measurement of effective PhysX inertia.

Essential contact/probing numerical data remain 240 Hz; RGB-D is checkpoint-only,
optional event clips are minimal, no continuous video or passive-camera dataset.
Target <100 MB per episode. Raw evidence stays private. Source hashes and compact
derived metrics/reports may be published. Preserve V6 and all engineering failures.
