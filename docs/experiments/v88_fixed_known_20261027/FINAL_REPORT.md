## 真实结论与边界

45600 实际最大 32.185°，未达到 90°，无目标后的有意义反向和独立验证，最终释放、退离和停车均未确认，保留 HARD_STOP_UNPARKED / NOT PASS。第二次抓取未建立双侧保持，软件将允许的部分手指接触错误地升级成不可复位锁存；未建立实测碰撞、超速或载荷硬危险依据。原实例在用户取消回复到达前已因诊断保留租期用尽关闭，实际总时长约 3h55m，不能改称用户取消导致关闭或跑满 4h。

共享修复仅把 staged_exit.safe_hold 的接触权限从 grasp_reference 是否存在，改为原运行时 intentional_contact() 的实际阶段权限。双侧验证之前也可能存在允许的指垫接触。原生非把手碰撞、关节、速度、载荷、停车、真实硬锁存保护保持原样，没有物体 ID 条件或阈值放宽。修复在第一实例关闭后才用于第二物体，未追溯改写第一例结论。

45290 的首个双侧抓取失败后，修复后的执行链真实完成释放、局部 4 cm 退离及原生停车，并在同一 World 从当前物体状态重新观察继续。随后 37.5 mm 的命令投影不可行、105.0 mm 的旧线性载荷预测中断均执行受控退出且保留 World。Agent 更换视角和当前深度假设、排除错误上层把手、分批更换抓姿、改变动作曲线/预载，并实际迁移底座两次。规划失败没有被解释成机械行程极限。

45290 原截止附近新增暴露了生命周期故障：command44 在截止前已真实确认释放、4 cm 退离和原生停车；但 session 在工作预算耗尽后继续等到总截止才重复验停，同时 launcher 到点写入 STOP_AND_EXPORT。该标记中断 .3 s 验停，最终导出 EXIT_UNVERIFIED（无硬载荷锁存），所以此前阶段停车通过不能代替最终停车成功。实际总时长 4h00m11.44s，其中 11.44s 为清理超时，未增加操作预算。该故障未在本轮闭幕后继续热修或追加物体实验。

六维 F/T 原始数据、辨识资格和操作成功分别评价。两例都有选中的局部正向模型，但均无反向回归数据、双向资格或完整独立验证。45290 前两个中断 FIT 整体排除；第三段在停滞前依既有资格规则留下正向可用前缀。离线不补拟合、不用验证选模型，不用隐藏 GT 指导动作。45600 惯量/阻尼/库仑力矩绝对相对误差为 0.0739% / 9.5910% / 0.8446%；45290 质量/阻尼/库仑力误差为 28.0138% / 0.1370% / 0.00193%。后者质量激励弱、条件数约 9849；小 FIT 残差不能当辨识成功。独立预测均为 N/A。GT 是仿真 authored 刚体组合，不是硬件实测。完整参数、单位与限定见 PHYSICS_ID_POSTHOC.json。

- 本次一处共享行为差异与 4 项故障注入：[PARTIAL_GRASP_EXIT_FIX.json](PARTIAL_GRASP_EXIT_FIX.json)。修复前 3 失败、危险碰撞保护 1 通过；修复后相关 62 项测试通过。
- 原始 0.600200 N·m 与 45134 超速故障重放沿用既有独立记录，不合并累计重叠测试数，也不把重放视为真实操作成功。
- 新增 3 组纯 CPU 载荷预测注入：有界上升后平台序列产生保守误报；缓慢 warning 与微小噪声不产生预测中断。该结论仅适用于注入序列，不能证明实测 105 mm 事件继续操作必然安全。
- 残留：旧 V75 线性载荷外推仍可能过早结束 B；最终命令非线性投影可能数值不可行且计算昂贵；吞吐资源预测被名义跟踪可疑条件门控，无法覆盖所有计算慢情形。当前没有外部“只停动作而保留 World”的受控接口。总截止与验停竞争造成最终 EXIT_UNVERIFIED。以上未靠热修改或放宽保护掩盖，P0 尚不能宣称彻底解决。
- 冻结资源审计 606 个物理文件、71 个旋转物体 owner 文件、956 个 release 文件及 22 个外部文件无改动。真正硬安全依然有效；45600 的软件锁存仍全部保留。
