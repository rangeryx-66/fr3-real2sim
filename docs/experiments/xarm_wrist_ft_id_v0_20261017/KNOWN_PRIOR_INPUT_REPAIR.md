# Explicit known-joint prior input repair

The original `native_g1_ft_identification.kinematic_prior()` used the origin of `body_at(0)` as the hinge origin. The moving body's origin is not generally on its joint axis. For 46427 the resulting perpendicular lever-arm error was approximately 395.412 mm. Original actor-created parameter files are retained but **invalid as joint dynamics estimates**. The native six-axis sensor streams remain valid.

The independent input adapter reads the permitted native joint anchor and its transform relative to the **actual recorded contact-bearing rigid body** (`manifest.door_link`, `l_0`). The legacy measurement field `T_moving_link` comes from `scene.door_contacts`, not the abstract revolute child. Applying the fixed body-to-joint transform to the measured body pose gives the world hinge line. An independent measured rigid-motion diagnostic agreed within approximately 0.5 micrometres perpendicular to the line; differences along the axis are irrelevant to projected moment. Both native USD rigid-body rest transforms match their URDF equivalents exactly (maximum elementwise error 0), confirming the scene generator's mass-property frame mapping.

This correction does not access hidden object dynamics, change robot actions, update the actor, or tune the numeric estimator. It creates `native_joint_prior/` beside each preserved original packet, hardlinks the same measurements and invokes the same frozen estimator with the corrected explicit kinematic prior. Source hashes are in `KNOWN_PRIOR_INPUT_REPAIR.json`. Established during case00's safe unloaded park, before subsequent recovery measurements; applied consistently to all packets. Original runtime updates and corrected external in-episode updates must be distinguished.

First slow case00 segment: the corrected provisional Coulomb term was about 0.04435 Nm, while inertia and viscous damping were unsupported by the conditional uncertainty. This is not a hidden-truth accuracy claim or physical-twin validation. No hidden parameter values were opened to make this correction or choose interactions.
