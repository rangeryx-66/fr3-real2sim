## 输入边界与薄适配

1. 正常闭合初态重新取得完整 RGB、真实模拟 optical-Z depth、K、相机外参、实测机器人状态。使用校准场景 RGB-D 相机，**不是腕部相机自主观测实验**。RGB 视频不充当深度。
2. 全帧 RGB-only SAM3 提取把手，按实测关节状态排除机器人；不使用实例 mask、GT crop、GT 把手 mesh、保存抓取变换或 GT 位姿修正。
3. 观测点云与周围面板深度生成九段纵向轮廓。不可见背面假设为“观测局部横向宽度”的厚度，轮廓间使用凸 loft；观测面板向内延伸 10 mm 仅供评分。**真实执行 colliders 没有改变**。
4. 沿用冻结候选族、接触/保持/任务评分结构与权重、18 候选 shortlist、15 个原扰动样本；其 ±1 mm 位姿、±0.5° 转动、±0.6 mm aperture 设置不是视觉置信界。摩擦兼容评分中的 μ=0.5 是继承的模型假设，非测得摩擦。评分 API 的 visual/native 两个标签在此适配中都表示同一观测几何加先验，不能误读为 GT/native handle surfaces。
5. 只继承登记 base station，重新生成视觉抓取、接近与 IK。原 30° 规划目标保留，物理短 runner 原样执行约 +3°。预抓取重观察、实测机器人遮挡排除、common-visible RGB-D 修正仅来自图像/深度；GT 对比只在独立离线 evaluator 中运行，无位姿误差 admission threshold。

保留的 known-model 依赖：登记站位、已知 hinge 几何、动态关节/活动部件状态、机器人及相机校准、原场景碰撞检查、登记 collider 身份用于物理接触报告。**不是 fully GT-free manipulation**。原 JawCenteredClosure、native G1 位置驱动、preload、Pink、对象/机器人物理与安全保护字节不变。没有新 force-quality、对称性或持续双侧接触门槛。

## 失败与 Shadow 差异

45600：两次 SAM3 推理正常运行但返回零个把手实例；无 RTX/显存/Isaac 初始化故障。Shadow 原本能生成计划，但其初始检测得分仅 0.271484；实际初始相机外参与机器人状态相同，RGB 未逐像素相同（平均绝对差约 0.189/255）。重观察图的低位细把手较暗，可能影响分割，尚不能据此证明唯一原因。共享 SAM3 3.1 checkpoint 加载有四个 convs.3 tensor missing-key 警告，在成功和失败进程中均存在；其因果作用本轮未证实、未事后改模型。**此例没有物理抓取尝试，不是接触失败，也不是初始化重试机会。**

45606：原自动视觉计划可达 30°，但 t=158.758 s 进入 CENTER 后只有左侧接触，到原 100 s 闭合预算结束仍未取得双侧保持。CENTER 实测相对活动部件 TCP 调整约 1.460 mm；最终 aperture 命令/实测约 18.662 / 18.731 mm；24,000 个闭合命令样本、0 次重开。左侧峰值 0.118618 N、右侧为零。闭合前最大门角约 0.0000743°，**不能算开门成功**。这是视觉候选与物理接触获取的未解决差异，不能仅凭该轨迹证明具体背面几何原因，也不能称作 IK/机械限位或开门控制器失败。

Shadow-only 捕获的失败输入与预执行视图修复已独立保留，没有计作接触尝试。观察修复采用共享的可见深度面/相机 FOV 规则；辅助 cabinet mask 缺失仅记诊断。规划目标由临时 3° 输入恢复为原 30°，在首个物理结果前统一冻结；三个可分割 Shadow 场景用已保存 RGB-D 完成离线重规划，没有重新物理执行。物理批次无案例间代码/参数调整。
