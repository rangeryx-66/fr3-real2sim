- 两次获取时滤波 L/R 载荷分别约 0.428/0.568 N、0.528/0.489 N；均执行原 1 s 保持。
- 记录到的原始 pad 峰值 L/R **2.289/1.266 N**，信息性载荷警告 4,690 个样本，**硬停止 0**。这些正常载荷没有因越过旧 2 N 数字而终止。
- 最大实测带载世界 TCP 速度 **12.382 mm/s**，没有旧 5 mm/s 致命分支；保留新策略 30 mm/s 带载测量停止界限。
- 全部记录中的最小关节裕度 0.419 rad；交互段 0.452 rad，成功恢复段至少 0.590 rad。原 0.05 rad 保护不变。

- 闭合器、Pink、夹紧力、原生 G1 执行器、碰撞体和物体物理均未调参。中央策略及其哈希保持 `1c98f9b`：`9ef5bd91047d46b56d3ba61b5bb704272bbd302eccbd14fdb3673e05183a8ee9`。

## 腕部 F/T 辨识：有用，但不能称为全部完成

使用原生固定接口六轴传递力矩，偏置及下游工具重力/惯性补偿后投影到已知铰链轴；未使用接触冲量和 GT 关节力矩替代 F/T。拟合模型仍为 `tau=I*qdd+b*qd+C*sign(qd)`。五段均为连续 240 Hz；导数在每段内独立处理，完整再开段留出。隐藏参数只在 actor 与全部 Agent 决策结束后进入独立评估。

| 项 | 拟合值 ± 条件标准差 | 事后 authored 真值 | 相对误差 | 可辨识结论 |
|---|---:|---:|---:|---|
| I，kg·m² | 0.18575 ± 0.18709 | 0.11218 | 65.58% | **未知/不支持可靠辨识** |
| b，N·m·s/rad | 0.29484 ± 0.09496 | 0.27697 | 6.45% | 数值接近，但激励低于残差基准，**仍不支持** |
| C，N·m | 0.017916 ± 0.000883 | 0.018081 | 0.916% | 本配置下支持有效库仑项估计 |

这里的标准差是条件线性近似，不是硬件校准置信区间。训练段的惯性/阻尼力矩 RMS 约 0.000231/0.002755 N·m，低于既有 0.004644 N·m 残差基准；回归秩 3 并不等于三个参数都被辨识。垂直铰链没有用于证明非零重力力矩。

独立再开段 **7.229 s**：F/T 力矩预测 RMSE **0.001198 N·m**；自由前向角度 RMSE **0.40191°**、末端误差 **−0.57835°**、速度 RMSE **0.002274 rad/s**。只初始化一次状态，后续不跟随 GT 轨迹；输入是留出段实测 F/T，不是预测未来交互力。有效训练范围约 **0.210–11.944°**，留出段到 15.085°，因此包含外推，不能全称为插值验证。改用原生实测初始速度的事后敏感性结果为 0.40239° / −0.57888°。

冻结在线流程也曾把失败首段的 2 个合格小时间 bin 纳入 FIT。事后排除这两个 bin，C 仅改变 0.0000410 N·m；I/b 仍不支持，角度 RMSE 为 0.3180°。这是单独标注的敏感性分析，**不是替换主结果或事后挑选最优模型**。没有据此追加试验。

## 时间与运行时问题

总计 **358.158 s 仿真 / 1,869.098 s 墙钟（31.15 min，含初始化与清理）**，全流程吞吐 0.1919 sim-s/wall-s。四个有效运动段：全 episode 摊销 **467.3 s/段**；成功恢复操作内含接近、抓取、保持及退出为 **120.1 s/段**。首次失败操作 336.9 s，恢复操作 480.3 s。

| 独占计时类别 | 墙钟 s |
|---|---:|
| 自动抓取排序与 IK | 481.8 |
| 物理步进与接触回调 | 367.3 |
| RGB-D / SAM3 / 增量几何 | 161.8 |
| 执行器提交 / 状态与 F/T | 133.7 / 143.9 |
| 实时碰撞与安全 | 51.0 |
| 数值收集与缓冲 | 69.3 |
| 诊断渲染与视频 / 最终 flush | 1.25 / 0.039 |
| Agent 无载等待 | 278.7 |

计时是独占函数计时，不能把并行 worker CPU 时间再加到墙钟上。其余包括初始化、轨迹生成、Python 编排和末端 worker 等待。没有运行等价旧场景，因此**不声称本次测得受控的 2× 全流程加速比**；耗时瓶颈已主要是规划、物理/传感读取及 Agent 等待，视频不是主要成本。

两个实际基础设施问题保持公开：

1. 最后两个数值 worker 超过原 60 s 限时，在线只完成前三段模型。事后定位 `NpzFile` 每次逐行索引都重新解压整列。仅修复为每列解压一次，全部实测数据更新 **6.744 s**，解码 3.054 s；前三段参数绝对差最大 2.54e−6，合成回归与完整验证段隔离检查通过。该修复发生在物理结果之后，**未重跑 Isaac**；以上最终模型标为事后完成，不冒充已在线得到。执行时旧 worker 哈希和事后处理器哈希均在 RESULT 中。
2. 登记的 1,800 s 外层预算与已批准动作/停车收尾重叠。对**仅本任务 owned launcher watchdog**提供最多 75 s 有记录收尾，实际超出 69.10 s；没有暂停 actor/PhysX、没有新增研究动作。`BOUNDED_COMPLETION_GRACE.json` 保留该预算偏差。正常进程返回 0，`SESSION_COMPLETE`，actor/launcher 均已退出。

另有一次可选诊断相机空帧索引警告；29 帧短片有效，必要数值记录无导出错误。没有把缺少可选帧变为执行失败。
