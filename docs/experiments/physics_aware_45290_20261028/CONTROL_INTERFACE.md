# Measured knowledge changes actual ABC commands

`agentic_interaction_v88.policy_commands` accepts measurement-derived model /
contact capability and a common qualified control menu. It neither reads plant
configuration nor accepts an Oracle method. A/B/C retain identical existing
feedback, actuator authority, path admission and hard supervision.

Reactive chooses the greatest demonstrated usable grip and fastest common
qualified reference. Stale and Updated use the same demand selector, differing
in measured-model age. Unsupported models or a prediction with no feasible
candidate return to the same reactive feedback; they cannot end an episode.
The selected preload/speed/acceleration become the actual `prepare_grasp` and
`acquire_execute` fields, not just a printed recommendation. Formal motions
must have independent VALIDATION roles without fitting intervals. Inputs and
the common menu are committed by content hash in each decision.

Seventeen policy/plant/command tests passed, including actual command-field
propagation, full-strength reactive control, no GT/Oracle formal method and
recoverable unsupported-model behavior. Physical comparisons remain pending.

Native startup qualification also exposed imported collider instance proxies.
Binding now traverses the actual proxies, authors only on each collider's
nearest writable local instance root, and verifies inherited physics material
at the collider. No de-instancing, geometry change or whole-assembly material
override is allowed. An offline check against the imported native USDs finds
one left-finger, one right-finger and one selected handle collider with verified
bindings. This is a USD binding check, not evidence of dynamic slip or benefit.
The pre-reset startup failure is retained separately with owned resource
release verified. Live native material readback/contact qualification follows.
