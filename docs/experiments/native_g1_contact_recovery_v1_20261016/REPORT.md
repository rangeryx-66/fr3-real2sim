# Contact-Feedback Recovery V1：两例有预算的物理开发验证

**结论：真实的“失败反馈 → 安全退出 → Agent 重新观察/选候选 → 重抓 → 短开门”已经发生一次。** 45936 恢复后增加 **2.9955°**；46427 首次增加 **3.0026°**。但 45936 在最后一次开门、释放和局部退让之后，返回原观察起点的路线预测碰撞，因此**不能把本轮说成两例完整 runner 都 PASS**。

## 最小共享接口及实际决策

| 操作 | 行为及边界 |
|---|---|
| `attempt_grasp_and_probe` | 原返回/接近、预抓取视觉修正、闭合、1 秒保持和短开门；返回获取、退化、传力和原保护结果 |
| `safe_release_retreat` | 停止拉动；检查有限 jaw sweep，在原驱动/慢闭合速度幅值下卸载释放；同一个力历史自然衰减后，检查并执行局部退让及无载返回 |

| `reobserve_and_replan` | 安全退出后获取新腕部 RGB-D，用原候选族/评分重新规划；记录并避免本 episode 已失败的候选族，不形成物体黑名单 |

```text
试抓/试拉 → 停止当前操作 → 受保护卸载/释放 → 检查并执行退让/返回

原 HARD 异常立即结束当前操作；不得恢复拉动、抬阈值或带载清空力历史。
```

**45936：** 第一图上半把手被腕部遮挡，Agent 查看 RGB、mask、深度和云后选择较高视点；保留长度 92.94 → 296.12 mm。首次获取后约 0.242 s 左正法向归零，保持结束前右侧持续增长；只开 0.0096° 时触发原 2 N 软警告。程序自动完成真实释放、40 mm 局部退让及无载返回，才交回反馈。Agent 看过实际接触图和曲线后，选择补充斜视图；新一代实测长度 92.75 → 295.87 mm。原规划器自动选出不同候选族，选中 TCP 相差约 177.6 mm、姿态约 179.7°；**这些是规划结果，不是手写偏移或历史成功模板**。恢复抓取完成 +2.9955°。

## 尚未解决：45936 最终返回路线

恢复开门后，**物理释放和局部退让已经完成**，载荷为零。随后检查的返回路线穿过把手碰撞体 `original39`，检查拒绝，路线没有执行。原始结果保留为 `SAFE_EXIT_UNAVAILABLE` / `runner_completion_success=false`，不改成 PASS。

这是**返回路线实现/规划不足**，不是机械极限、实际碰撞或“所有恢复路径均耗尽”的证据：当前实现只在选中退让后检查这一条返回路线，未联合尝试其他退让—返回组合。下一项最小工程修复应是利用现有检查/路线函数，从当前已释放状态联合选择有限退让与无载观察路线，避免依赖旧的闭门 pregrasp 路径；不弱化碰撞、不再调抓姿评分。本轮冻结批次未修改或重跑此项。

## Native G1 有限接口核查

实际为一个有限 implicit position drive、五个 mimic 约束，非真实 G1 力控。主关节 `drive_joint` 在运行排序 index 7；mimic gearing -1、offset 0。原 stiffness 10 N·m/rad、damping 0.1 N·m·s/rad；USD 角目标用度，runtime q/dq 用 rad/rad·s⁻¹。本轮未发现明确单位、符号或绑定错误。

逐步回读的主驱动 max-effort 约 **2.640–3.300 N·m**；启动元数据里的 50 N·m 不是运行期 cap。位置/速度目标、master/mimic 状态和实际指体世界位姿均已记录；三次试抓记录中位置目标与指体位姿读取完整。

**独立 implicit 电机输出、每个 mimic 约束的求解冲量不可用。** 显式 effort=0 只代表未叠加外加 torque，不表示电机输出为零；projected joint reaction 不冒充电机输出。原生接触冲量/点/法线/碰撞体记录仍可用。法向数据不是完整交互 wrench，接触点不是压力面积；单侧正法向消失不能独立证明物理分离。
